## 📖 Overview
<a id="overview"></a>

**PianoRollComposer** is a powerful music production station for Windows that allows you to create stunning compositions with up to 128 instruments and 61 drum tracks. This innovative application revitalizes the old Piano Roll MIDI sequencing system, providing a user-friendly environment where musicians can compose graphically, without the need for traditional scores. 

With the **latest version** of PianoRollComposer, you'll have access to an extensive range of features that ensure a complete functionality for all your music production needs. Download now to explore its capabilities and take your music to the next level!
